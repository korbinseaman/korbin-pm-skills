# 证据规则

## 发现等级

- `observation`：单条数据或单个样本现象。
- `pattern`：多个独立样本出现、且无明显反证的重复现象。
- `insight`：能够解释模式并影响决策的因果假设，仍需验证。
- `recommendation`：基于证据、约束和风险提出的下一步行动。

不要把观察直接写成洞察。

## 置信等级

- `high`：真实数据中多源一致、样本覆盖充分、反例已检查；合成数据不得使用。
- `medium`：真实数据中重复出现且证据链完整，仍有边界。
- `low`：小样本、单一来源、合成数据或存在重要替代解释。

所有合成数据发现最高为 `low`，表述为待真实研究验证的假设。

## 证据引用

- 数字：记录题目 ID、分子、分母、筛选条件和缺失数。
- 定性：记录匿名 `response_id:question_id`；合成引语前加“模拟原话”。
- 不使用无法回溯的“很多用户”“普遍认为”。

## 来源隔离

- 回答工作簿是问卷发现和回答原因的唯一证据来源。
- `questionnaire-design.html` 是研究意图，不能支持“用户认为”类结论。
- 不读取 `personas.json`、`persona_audit.json`、`persons/` 或其他逐人画像文件。
- 可选的 `persons_summary.txt` 是合成样本构建材料，不能计入主题频次、痛点发生率、引语或分群；不得用它解释或补齐缺失回答。
