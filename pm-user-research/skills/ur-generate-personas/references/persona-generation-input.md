# 用户画像生成输入

本 Skill 直接接收用户或调用方明确提供的参数，不读取其他用户研究 Skill 的产物或对话。

## 输入字段

| 字段 | 要求 | 说明 |
|---|---|---|
| 课题 | 必选 | 产品、服务或行为场景，只用于界定相关经验 |
| 全量候选用户群体 | 必选 | 产品或功能可能覆盖的全部主要群体，不能只列目标群体 |
| 目标用户 | 可选 | 本次重点覆盖的候选群体；未提供时默认覆盖全部候选群体 |
| 纳入条件 | 可选 | 用户明确要求的人群条件，不等同于已经具有产品经验 |
| 排除条件 | 可选 | 仅采用用户主动提出并确认的排除条件 |
| 画像数量 | 可选 | 默认 100，不能少于候选群体数量 |
| 群体配额 | 可选 | 各候选群体人数；未提供时均衡覆盖 |

## 完整性处理

1. 课题或全量候选用户群体缺失时先询问，不自行从问卷、报告或其他 Skill 文件推断。
2. 目标用户未提供时不追问，默认等于全量候选用户群体。
3. “当前没有相关经历”“尚未使用过该功能”“不确定是否使用过”不能自动成为排除条件；这些人可能是潜在用户。
4. 用户给出配额时，人数之和必须等于画像数量；否则先请用户修正。
5. 不接收研究目标、产品决策、假设、概念方案、问卷题目或预期答案，避免人物提前知道研究内容。

## 传给生成阶段的输入摘要

```text
课题：手机照片整理
全量候选用户群体：学生、上班族、宝爸宝妈、内容创作者
目标用户：上班族、宝爸宝妈
纳入条件：智能手机用户
排除条件：无
画像数量：100
群体配额：未指定，均衡覆盖
```

这是当前 Skill 内部的输入摘要，不保存为任务级共享文件，也不作为其他 Skill 的上下文接口。
