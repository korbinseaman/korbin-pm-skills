# AI造假与模板化风险检查

只能输出风险信号，不得宣称证明真伪。

## 风险信号

- `unsupported_specificity`：回答出现画像和题目都未提供的精确日期、金额、版本、地点或内部事实。
- `persona_conflict`：回答直接违背画像事实锚点。
- `cross_response_duplicate`：不同画像开放题长文本高度相同。
- `template_language`：大量使用相同句式、完整对称列表或“作为一名……”等角色扮演痕迹。
- `over_consistency`：所有量表方向完全一致且开放题没有权衡或不确定性。
- `knowledge_boundary_breach`：画像明确不知道的内容却给出专业结论。

## 判定原则

- 精确值只在缺少支持时标记；题目选项中的值不算虚构。
- 重复短答案和封闭题选项不算模板化。
- 相似度、措辞规则和长度阈值只能生成 `warning`。
- 每个批次至少人工抽查一条高风险和一条低风险记录。
