# 报告质量审计

报告交付前逐项检查：

- [ ] 标题、研究目标结论和限制部分一致披露数据来源。
- [ ] 研究目标结论回答研究目标而不是复述流程。
- [ ] 样本量、完成率、缺失、质量等级和模型分布可见。
- [ ] 数据清理前后的完成样本数、剔除用户 ID 与理由、待人工复核记录可追溯；原始 Excel 未被改写。
- [ ] 报告明确写出从回答 Excel 文件名取得的 `run_id`，报告目录使用同一后缀。
- [ ] `questionnaire.md` 的题号、题型、选项、量表和逻辑提示已成功解析，研究目标来自 `survey-design-desc.html`。
- [ ] 每个研究目标映射到证据或明确标记证据不足。
- [ ] 每个百分比显示分母；多选题注明总和可能超过 100%。
- [ ] 量表题同时显示均值和标准差；有效样本少于 2 时明确不计算标准差。
- [ ] 交叉分析只使用回答工作簿中的分组题，显示每组 `n`；小样本、空组和多选题的多重响应限制已披露。
- [ ] 信效度分析仅用于满足题项与样本条件的量表；不适用时明确说明，不虚构 α、因子或效度结论。
- [ ] 每个主要发现有证据 ID、`n/N`、置信等级和反例检查。
- [ ] 图表有标题、分母、文字解释和可读的静态 SVG。
- [ ] 页面可按一个或多个封闭题选项叠加筛选，当前筛选样本数与封闭题频数、百分比、量表均值/标准差会同步更新。
- [ ] 筛选不会自动改写研究目标结论、主题、交叉/量表分析或建议；页面已清楚限定动态统计范围。
- [ ] “保存当前筛选报告”、PNG 与 SVG 图片下载均已在离线浏览器实际验证；下载不会上传数据。
- [ ] 页面内嵌的筛选数据不含用户 ID、姓名、任务 ID、模型、开放回答或回答原因。
- [ ] 建议说明证据强度、影响、成本/风险和下一步验证。
- [ ] 不存在伪造引语、填补缺失或因果过度解释。
- [ ] 至少抽查 3 项统计与 Excel 原行一致，至少抽查 3 个证据 ID 可回到 Excel 单元格。
- [ ] 如读取 `persons_summary.html`，其内容只作为样本构建背景披露，没有被当作回答证据、分群或市场比例。
- [ ] HTML 离线打开，无外部 CDN、远程字体或脚本依赖。
- [ ] 已实际打开 HTML 检查桌面与窄屏布局，图表文字没有明显截断或重叠。

任一输入、来源披露、统计抽查、证据回溯、离线或视觉检查失败，不得交付。所有检查及修订记录写入必需的 `report_quality.md`。
