# Word 报告规范

## 信息结构

与 Markdown 保持一致：

1. 调研范围。
2. Output 1 — 产品定位 + Feature Matrix。
3. Output 2 — 竞品机制与真实界面截图。
4. Output 3 — 定位可视化 + 原始数据 + 评分依据 + 重生成命令。
5. Output 4 — 竞品差异与 HarmonyOS 方向。
6. 来源 / 证据说明。

## 排版规则

- 横向矩阵过宽时可使用横向页面。
- 跨页表格应重复表头。
- 不要为了把表格挤在一页而把字号压得过小。
- 真实竞品截图必须保持可辨认尺寸；允许聚焦裁剪，但不得改变原意。
- 截图旁标注来源、版本、地区、日期（能获取到时）。
- “请人工确认”必须直接可见，不能只藏在脚注。
- Output 3 的原始数据应放在图表附近，便于用户修改。
- 图表重生成命令使用等宽字体展示。

## 生成质量门槛

实际生成 `.docx` 时，必须遵守运行环境中的 Word/文档生成与渲染检查流程，确认宽表、截图、图表没有被裁切或错位。
