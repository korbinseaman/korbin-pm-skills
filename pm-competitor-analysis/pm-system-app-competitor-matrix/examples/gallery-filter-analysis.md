# 示例 — 图库筛选竞品分析

## 输入

```text
目的：差异化竞争
系统 APP：图库
功能模块：照片筛选
调研主题：存储位置、云同步状态与组合筛选
特别关注项：入口、多条件组合、结果状态反馈
```

## Research Question 示例

> 主流图库如何帮助用户按本地/云端与同步状态快速缩小照片范围，组合筛选和结果反馈的体验差异在哪里，HarmonyOS 是否存在可形成差异化的筛选效率优势？

## FeatureSchema 示例

用户任务：在大量照片中快速找到满足存储/同步条件的目标内容。

- 入口
  - 首页筛选入口
  - 搜索结果筛选入口
- 存储位置
  - 本设备/本地
  - 云端
  - 外部/家庭存储（如适用）
- 同步状态
  - 已同步
  - 未同步
  - 同步异常（如产品暴露）
- 组合能力
  - 多条件组合
  - 跨模块组合
- 反馈
  - 当前筛选状态可见
  - 一步清空/重置

本示例只说明拆解形态。正式分析必须重新检索当前产品与证据。
