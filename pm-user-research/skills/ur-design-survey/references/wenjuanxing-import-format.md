# 问卷星文本导入格式

`questionnaire_for_wenjuanxing.txt` 是从 `questionnaire.md` 生成的问卷星纯文本导入文件。采用问卷星官方文本 DSL 的兼容写法；文件使用 UTF-8 编码。

官方依据：

- [问卷星：从文本创建问卷](https://www.wjx.cn/help/help.aspx?helpid=138)
- [问卷星官方 wjx-ai-kit：DSL 文本格式](https://github.com/wjxcom/wjx-ai-kit/blob/master/wjx-api-sdk/README.md#dsl-%E6%96%87%E6%9C%AC%E6%A0%BC%E5%BC%8F)

## 文件结构

第一行是标题，之后是问卷描述；单独一行 `===` 结束描述。题目之间空一行。

```text
手机图库 AI 功能使用与需求调研
请根据您的实际经历作答。
===

1. 您的性别是？ [单选题]
1. 男
2. 女
3. 不愿透露

2. 您最需要哪些功能？（最多选择 3 项） [多选题]
1. 找到特定照片
2. 自动整理照片

3. 您还有什么建议？ [填空题]
```

## 转换规则

| `questionnaire.md` 题型 | 问卷星标签 | 题体格式 |
|---|---|---|
| 单选题 | `[单选题]` | 选项逐行编号 |
| 多选题、Top-N题 | `[多选题]` | 选项逐行编号；选择上限保留在题干 |
| 填空题、开放题 | `[填空题]` | 不生成伪选项 |
| 量表题 | `[量表题]` | 使用 `最小值~最大值`，如 `0~10` |
| 排序题 | `[排序题]` | 待排序项逐行编号 |
| 矩阵量表题 | `[矩阵量表题]` | 使用 `行：`、`列：` 分组列出内容 |

- 删除题号中的 `Q` 前缀和题干中的“（必填）/（选填）”；平台必填状态需在导入后配置。
- 不写 Markdown 标题、引用符、列表符或研究者注记。
- 不把题目关联、跳题逻辑、选项关联、互斥、随机化和“其他”填空配置写进 TXT；文本导入后按 `questionnaire.md` 配置。
- 题目顺序、题干语义和选项顺序必须与 `questionnaire.md` 一致；题型等价转换必须记录在 `survey-design-desc.html`。
- 题型或材料无法按上表无损表达时返回 Step 5 调整，或把该项列为导入后人工配置，不得猜测语法或静默漏题。

## 导入后复核

逐题核对题型、必填、选项顺序、多选上下限、互斥项、“其他”填空、显示条件、跳转、动态选项、量表端点和结束页。至少试答完整经历、无经历和边界答案三条路径后再发布。
