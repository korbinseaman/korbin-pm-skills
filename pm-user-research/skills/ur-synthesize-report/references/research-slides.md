# 调研报告幻灯片规则

## 1. 页面内容：固定 4 页，无封面

| 页 | 回答什么 | 必放数据/内容 | 页末交付 |
|---|---|---|---|
| P1 当前体验诊断 | 用户当前怎么做，什么问题值得继续查？ | ① 当前行为；② 同一任务的困难；③ 问题后果（有数据才放） | 一个待定位的体验环节 |
| P2 体验机会与采用边界 | 用户想得到什么结果，采用需要满足什么条件？ | ① 需求选择；② 采用条件；③ 备选需求或拒绝原因（有数据才放） | 一个竞品待查机制＋一个原型验证问题 |
| P3 竞品分析输入 | 下一步具体查什么？ | 最多 3 项，按第 4 节填写 | 可执行的竞品任务 |
| P4 体验设计输入 | 下一步具体设计、验证什么？ | 最多 3 项，按第 4 节填写 | 可执行的原型测试任务 |

## 2. 结论页：每页一个判断，2–3 项数据

| 要素 | P1 怎么写 | P2 怎么写 |
|---|---|---|
| 标题 | “【任务】目前主要用【方式】完成，【困难】较常见” | “【目标结果】选择较多，采用时主要考虑【条件】” |
| 数据① | 已发生的行为：工具使用、任务频率、实际付费经历，选一项 | 期望结果：任务首选或需求选择，选一项 |
| 数据② | 同一任务已测困难：失败、耗时、满意度或操作障碍，选一项 | 已测采用条件：效果、试用、隐私、可控性或价格，选一项 |
| 数据③（可选） | 已测后果：放弃、返工或转用工具 | 同口径备选需求，或拒绝采用理由 |
| 解释 | 一句话说明哪些问题需继续定位 | 一句话说明机会成立需要什么条件 |
| 限制 | 写一个影响标题判断的证据缺口 | 注明自报意愿；未测实际行为则不推断使用/支付 |

**数据写法**：`Q3｜选择先试用｜41/60（68.3%）｜多选`。每项注明支持标题的哪部分；原话只解释，不占定量数据名额。

**证据不足**：缺行为/困难，或缺需求/采用条件，列出缺项并停止正式幻灯片；不得从“想要功能”补造困难。

## 3. 图表：按要说明的问题选择

| 要说明什么 | 数据条件 | 用什么图 | 怎么画 |
|---|---|---|---|
| 当前方式的整体构成（P1） | 同一单选题，全部选项互斥且合计 100% | 100% 水平堆叠条 | 画完整构成；另一项困难证据放数字卡 |
| 需求/困难中谁选择更多（P1/P2） | 同题选项，同口径有效样本 | 水平条形图 | 按比例降序；多选注明“可重叠”；不要据此推断商业排期 |
| 行为＋困难，或需求＋条件（P1/P2） | 跨题、不同分母或部分选项 | 独立水平百分比条 | 固定 0–100%；每条单列分母；不相加、不画成漏斗 |
| 采用态度的整体构成（P2） | 同一单选题的完整互斥选项 | 100% 水平堆叠条 | 完整展示愿意/犹豫/拒绝等原始选项；需求证据放数字卡 |

- 每页 1 个主图，辅以 0–2 个数字卡；全页仍为 2–3 项支撑数据。
- 不用饼图、圆环或单批次折线；多选不用堆叠构成。
- 排序第一选择、分群或漏斗先做专项统计；不得用选项分布代替。
- 内置生成器目前只支持独立条/完整单选堆叠；涉及“主图＋数字卡”时另作版式适配，三种输出同步，不能宣称内置模板已支持。

## 4. 后续输入：按行填写，不写长段落

| 页面 | 每条输入的固定格式 | 示例（仅示意，不是研究发现） |
|---|---|---|
| P3 竞品分析 | 研究证据 → 复现任务 → 比较机制 → 待查问题 → 决策用途 | Q4 选择先试用 → 用同图修图并走到付费 → 预览范围、免费次数、提示节点 → 未付费可看什么效果？ → 确定试用边界 |
| P4 体验设计 | 用户/场景 → 期望结果 → 研究证据 → 交互假设 → 测试判据 | 首次试用修图用户 → 判断效果是否值得付费 → Q4 → 假设提供前后对比与费用说明 → 观察能否比较效果、解释费用并作选择 |

每页最多 3 行；只选与本次结论相关的内容。未调查的竞品能力写“待查”；交互方案写“假设”；未测基线不编提升目标。

## 5. 写入底稿

| 内容 | 字段 |
|---|---|
| P1/P2 顺序 | `page_role=current_state / needs_and_conditions` |
| P1 必需证据标签 | `current_behavior`＋`friction` |
| P2 必需证据标签 | `need_priority`＋`decision_condition` |
| 每页结论 | `title, research_question, goal_ids, supporting_data, interpretation, product_implication, counterevidence_or_limit` |
| 每项数据 | `question_id, option_label, evidence_angle, proves`；匹配原统计 |
| 竞品输入 | `input, compare_dimensions, verification_question, decision_use, question_ids/evidence_ids, status` |
| 设计输入 | `input, design_implication, validation_question, question_ids/evidence_ids, status` |

状态：事实 `research_finding`；假设 `product_hypothesis`；待查 `to_verify`。合成数据标明“仅用于假设生成”。

## 6. 验收：六项全部通过

- [ ] 4 页无封面；前两页各一个结论、2–3 项互补数据。
- [ ] 结论回答研究目标；没有将题目结果逐题搬上页面。
- [ ] 数字、题型、分母能回到 Excel 核对。
- [ ] 没有把意愿当行为、并列比例当关联、关联当因果。
- [ ] 后两页明确任务、机制/假设和判据，能直接开展工作。
- [ ] PPTX、HTML、浏览器下载一致，渲染无重叠或截断。
