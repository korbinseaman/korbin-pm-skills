# 分析方法选择

## 数据清理与描述性统计

- 先检查完成回答是否存在问卷外选项、重复排序、选择数超限、量表非数值/越界，或违反已解析的结束答题、排他项跳题、显示条件；这些结构性或逻辑无效回答从可分析样本剔除，并记录用户 ID 与理由。
- 对照题目逻辑、筛选条件和本次研究诉求人工复核语义不自洽或明显不相关的回答。人工剔除必须留下具体理由，不能删除原始工作簿或只保留一个“已清洗”数字。
- 先报告原始答卷数、清理剔除数、可分析基数和缺失；有状态及计算依据时报告完成/失败和完成率，未知指标不写成零。
- 单选：频数与百分比，百分比必须显示本题实际分母。
- 多选：按选择人次和受访者占比，明确总和可超过 100%。
- 量表/NPS：频数、均值、标准差、中位数、最小值和最大值；少于两个有效值不计算标准差。
- 排序：报告平均名次和第一选择频数；小样本避免伪精确小数。
- 合成样本不得作显著性、总体或市场规模推断。真实样本默认描述性分析；需要推断时先核验抽样设计与方法条件，不将非概率样本比例宣称为总体比例。

统计只从已锁定 Excel 的清理后有效答卷计算。合成模式的失败行进入总样本、失败数和完成率，但不进入题目分母。真实模式依据已确认的状态及规则判定有效性，不要求模拟器状态列。空白结合已提供的跳题规则与前序答案区分；无法确定时标为“空白/未作答”，不擅自插补。

已提供的研究设计与分析建议用于确定联读和分群方向，不是统计结果。合成模式题目结构以 `questionnaire.md` 为准；真实模式以正式问卷/字典及已确认列映射为准，不猜测未知编码和逻辑。

## 交叉分析与量表检验

- 交叉分析只使用回答工作簿中真实存在、与研究目标相关的分组题。每个分组 × 目标题的单元格显示组内 `n` 与百分比，并同时报告总体分母；不要因用户画像或汇总材料推断年龄、性别或群体归属。
- 多选的交叉以每个选项为一次多重响应计算，不能将多个选项合成互斥类别。任一有效组过小、空组或缺失过多时，保留该情况并只作探索性描述。
- 信度仅用于同一构念、题意方向一致且至少 3 个同量表题项。可报告 Cronbach’s α、有效样本数、剔除题项及原因；不满足前提则写“不适用”。
- 效度不能由一次小型合成样本自动证明。结构效度检验仅在题目设计、样本和方法条件满足时执行；不适用时记录题项—构念映射、条件缺口及后续验证，不虚构因子、拟合指标或效度等级。

## 开放题与回答原因

1. 把原文拆成单一含义的观察，保留 `response_id:question_id`。
2. 用贴近原话的初始编码，不先套研究者结论。
3. 聚合为主题，并记录支持、反例、分歧和未覆盖情形。
4. 频次表示当前样本出现情况，不等于总体流行度。
5. 每项洞察至少包含情境、行为/问题、影响和产品含义。

当前 Skill 只处理问卷中的开放题和“回答原因”，不接收独立访谈记录。合成批次的证据 ID 以用户 ID 为匿名响应 ID，例如 `P001:Q5`；回答原因追加 `:reason`。同一受访者在同一主题内出现多条文本时，频次 `n` 仍按独立受访者去重。

## 样本构成说明

- 默认不读取画像文件。只有在需要交代合成样本如何构造时，才可读取 `persons_summary.html`。
- 该汇总只能作为批次级背景说明，不能映射到单个答卷，也不能用作分群字段、主题证据或回答原因。
- 任何分群都必须来自回答工作簿中的明确字段，并显示每组 `n`；小样本只描述探索性方向，合成发现最高为 `low`，真实发现按证据与偏差评级。

## 证据组合

用封闭题定位“本批次出现了什么”，用已有开放回答和回答原因解释“为什么/如何”；没有文本时不补造原因。证据矛盾时保留矛盾并提出验证计划，不强行统一。真实与合成数据不自动合并，分别按主 Skill 的来源差异披露与解释。
