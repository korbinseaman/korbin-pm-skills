# 示例 — 云图库同步 / 删除追溯竞品分析

## 输入

```text
目的：差异化竞争
系统 APP：云图库
功能模块：多设备同步与删除
调研主题：离线设备重新联网后的历史删除、同步时效、删除追溯与恢复
```

## 可拆解的 Feature 组

- 同步模型
- 历史删除传播
- 离线设备重新联网行为
- 是否存在同步有效期/时效机制
- 最近删除保留时间
- 恢复范围
- 删除时间/设备/来源是否可见
- Activity / Audit Log
- 风险提醒与用户可解释性
