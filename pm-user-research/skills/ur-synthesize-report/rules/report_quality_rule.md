# 报告质量审计

报告交付前逐项检查：

- [ ] 标题、研究目标结论和限制部分一致披露数据来源。
- [ ] 研究目标结论回答研究目标而不是复述流程。
- [ ] 原始答卷数、剔除数、可分析数和缺失可见；完成率等指标有计算依据，未知不写为零。合成模式展示运行质量和模型分布，真实模式展示已有采集信息与偏差，不要求模拟器指标。
- [ ] 数据清理前后的完成样本数、剔除用户 ID 与理由、待人工复核记录可追溯；原始 Excel 未被改写。
- [ ] 合成模式从 Excel 文件名取得 `run_id`；真实模式保留原批次 ID 或明确标注生成的分析运行 ID，输出与底稿标识一致。
- [ ] 题目、编码、量表和逻辑有来源：合成模式解析正式问卷与设计说明；真实模式核对实际列映射及已有问卷/字典，未知项和缺少正式目标明确标注，不补造设计。
- [ ] 每个研究目标映射到证据或明确标记证据不足。
- [ ] 每个百分比显示分母；多选题注明总和可能超过 100%。
- [ ] 量表题同时显示均值和标准差；有效样本少于 2 时明确不计算标准差。
- [ ] 交叉分析只使用回答工作簿中的分组题，显示每组 `n`；小样本、空组和多选题的多重响应限制已披露。
- [ ] 信效度分析仅用于满足题项与样本条件的量表；不适用时明确说明，不虚构 α、因子或效度结论。
- [ ] 每个主要发现有证据 ID、`n/N`、置信等级和反例检查。
- [ ] 图表有标题、分母、文字解释和可读的静态 SVG。
- [ ] 页面可选择筛选题目及一个或多个选项；同题选项为“任一满足”，不同题目条件为“同时满足”，当前筛选样本数与封闭题频数、百分比、量表均值/标准差会同步更新。
- [ ] 可按同一筛选样本选择分组题和目标题完成交叉分析；每组显示组人数、目标题有效分母与空白数，每格显示选项人数和以有效分母计算的百分比；空组保留为 `—`，多选/排序分组的重叠与目标题的非互斥限制可见。
- [ ] 普通分析逐题展示，每题独立切换表格、饼图、圆环、柱状、条形、折线。表格保留零频选项和有效填写人次；多选题饼图/圆环按选择人次归一化并注明，折线不暗示时间趋势。
- [ ] 筛选不会自动改写研究目标结论、主题、研究者预设的交叉/量表分析或建议；页面已清楚限定动态统计范围。
- [ ] 下载窗口支持真正 DOCX、PPTX、XLSX，ZIP/XML 结构和文件可重新打开均已验证；下载保留当前筛选条件、分析页、分母和全批次正文口径。Office 和 CSV 均在本地完成，不上传数据。实际浏览器下载/视觉检查未完成时必须如实标记，不得将单元测试当作视觉验收。
- [ ] 页面没有“保存报告”“导出PNG”“导出SVG”控件；保留下载报告，结论 PPT 为2–3页（生成器默认3页）且有数据图表、来源和有效分母。
- [ ] 页面内嵌的筛选数据不含用户 ID、姓名、任务 ID、模型、开放回答或回答原因。
- [ ] 建议说明证据强度、影响、成本/风险和下一步验证。
- [ ] 不存在伪造引语、填补缺失或因果过度解释。
- [ ] 至少抽查 3 项统计与 Excel 原行一致，至少抽查 3 个证据 ID 可回到 Excel 单元格。
- [ ] 如读取 `persons_summary.html`，其内容只作为样本构建背景披露，没有被当作回答证据、分群或市场比例。
- [ ] HTML 离线打开，无外部 CDN、远程字体或脚本依赖。
- [ ] 已实际打开 HTML 检查桌面与窄屏布局，图表文字没有明显截断或重叠。

任一输入、来源披露、统计抽查、证据回溯、离线或视觉检查失败，不得交付。所有检查及修订记录直接展示在 HTML 的“问卷质量报告”Tab，不单独生成 `report_quality.md`；区分自动结构检查与人工/浏览器验收，未检查项明确标为待检查。

- [ ] 四个 Tab 的点击与键盘切换正确；结论页按背景与目的、用户现状、诉求与痛点、关键结论展开，旧的三个重复正文区块已移除。分群分析、全批次统计、清理记录和限制只在“问卷质量报告”。后两页隐藏筛选并使用全批次数据，导出内容相互隔离，三页结论 PPT 图表与原统计一致。

当前报告交互要求：四个 Tab 分别为普通分析、交叉分析、调研分析结论、问卷质量报告。结论 PPT 按背景/目的与现状、诉求与痛点、目标对应关键结论组织2–3页，每页含数据图表及实际分母。图形按百分比绘制并标注，缺失信息明确标记，不补造研究背景或原因。
