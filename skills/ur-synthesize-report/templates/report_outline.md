# HTML 报告结构

1. 标题与醒目的数据来源披露。
2. 研究决策、研究目标、问卷方法和证据边界。
3. 批次 `run_id`、总样本、完成/失败、清理剔除记录、可分析样本、数据质量和实际模型分布。
4. 单题描述统计：单选/多选的频数与百分比，量表的均值与标准差，排序的首选与平均名次。
5. 高级与交叉分析：分组交叉、量表信效度的结果，或清楚说明不适用的原因。
6. 关键发现：每节按“发现 → 图表/证据 → 解释 → 限制 → 产品含义”。
7. 分群观察与反例。
8. 痛点和需求优先级。
9. 建议：立即修订研究工具、下一步真实研究、产品探索项。
10. 限制、未回答问题和附录证据索引；证据索引能定位到 Excel 用户行与题目/回答原因列。

HTML 使用单栏阅读流、系统字体、高对比度颜色、响应式布局和内嵌 SVG。不要把报告做成只有指标卡和图表的仪表盘。

合成数据必须说明其不能替代真实研究。若读取 `persons_summary.txt`，仅将其作为“样本构成说明”单独披露；不得与回答结果共用一张比例图，也不得把它写成回答证据或分群结果。
