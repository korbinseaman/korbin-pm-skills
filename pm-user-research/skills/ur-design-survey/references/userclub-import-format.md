# UserClub 批量导入格式

用于把 `questionnaire.md` 同步为公司内部 UserClub 平台可批量导入的 `questionnaire_for_userclub.txt`。

## 文件规则

- 使用 UTF-8 纯文本，不包含 Markdown 标题、代码围栏、题号、必填标记、问卷说明或逻辑配置。
- 问题之间空一行；题干和选项不增加缩进。
- 题目顺序、题干语义和选项顺序必须与 `questionnaire.md` 一致。

## 单选题

题干格式为 `【单选题】题干`，每个选项格式为 `-选项`，短横线后不加空格。

```text
【单选题】您的性别是？
-男
-女
-不想透露
```

## 多选题

题干格式为 `【多选题】题干`，普通选项格式为 `o-选项`，前缀前后不加空格。允许受访者填写内容的“其他”项不加 `o-`，写成 `选项名称-----------`。

```text
【多选题】您喜欢的功能有？
o-功能A
o-功能B
其他功能-----------
```

## 同步与阻断规则

- 单选、多选题必须逐题导出；配置说明和跳题逻辑留在 `questionnaire.md`，导入后在平台内配置。
- 将“其他（请说明）”输出为 `其他-----------`；如有具体名称，则保留名称并追加 11 个半角短横线。
- 当前规格只定义单选题和多选题。出现量表、矩阵、排序、Top-N 或填空题时，先返回 Step 5：能保持证据目标时等价改写为单选/多选，不能等价改写时请求用户补充该题型的平台格式。
- 未覆盖全部题目、题型不受支持、选项为空或前缀错误时不得交付该文件。
