# 示例 — AI 修图竞品分析

## 输入

```text
目的：功能借鉴
系统 APP：图库
功能模块：AI 修图
调研主题：一键修图、生成式编辑与专业控制能力
```

## 动态竞品选择示例

除默认手机厂商外，可以根据当前市场选择头部互联网/专业修图产品，因为这些产品往往在 AI 编辑交互、模板/资源规模和商业机制上具有较高参考价值。

## 可拆解的 Feature 组

- 一键增强/一键美化
- 生成式消除/修复
- 扩图/重构图
- 人像/背景编辑
- 画质增强
- 专业控制
- 模板/资源规模
- 处理速度/输出限制
- 与课题相关时的价格/免费额度

## 可寻找的定量证据

在可靠且口径可比时，可搜索：

- 处理时延；
- 输出分辨率；
- 模板/效果数量；
- 免费额度/积分成本；
- 功能使用率/渗透率；
- 有透明方法论的效果质量 Benchmark。
