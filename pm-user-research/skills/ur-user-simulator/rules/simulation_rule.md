# 模拟执行规则

1. 主任务优先读取 `questionnaire_for_simulator.md`，缺失时才回退到 `questionnaire.md`；同时读取 `persons_summary.html` 内嵌的 `persona-summary-data` JSON，只核对单人画像文件路径，每个执行单元开始答题时再读取自己的 TXT 画像。
2. 一人一个独立任务和独立模型会话。任务只包含问卷路径、单人画像路径、输出要求和禁止虚构规则，不得共享其他画像或回答。
3. 模型只能使用该画像中的事实、问卷材料和普通常识。无依据时选择问卷提供的“不适用/没有/不确定”，不得补造私人经历。
4. 所有用户任务统一提交并行执行，实际并发遵守平台或供应商限制；失败只做有限重试，不用默认答案补齐。
5. 每个任务按题序先执行题干后的显示/跳转规则，再回答选项；遵守动态选项、排他和结束规则。临时答卷只保存题号、答案和可选回答原因。
6. 自定义模型按预置顺序轮询分配；原模型重试耗尽后才切换下一可用模型，并记录最终实际模型。
7. 临时答卷写入并重新读取成功后才能标记完成。恢复运行时复用用户 ID 正确的已有临时答卷，不覆盖已完成记录。
8. Excel 导出并回读校验成功后删除临时答卷；最终目录只保留 Excel 汇总和质量报告，不保留个人答卷、任务清单、原始响应或结构化 JSON。
